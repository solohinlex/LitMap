# AGENTS.md — LitMap

Вопросы и сводки по литературным корпусам. Несколько проектов изолированы: у каждого
свой список папок и свой индекс. Папки с текстами только читаются.

## Язык и стиль

- Код, сообщения, докстринги и ответы пользователю — на **русском**.
- Типизация: Python 3.12+, везде `from __future__ import annotations`.
- Аннотации типов обязательны для сигнатур функций и методов.
- Никаких комментариев в коде, если их не просили.
- Приватные хелперы с префиксом `_`, например `_fail`, `_resolve`, `_require_env`.

## Структура проекта

- Пакет: `src/litmap/` (src-layout, собирается hatchling).
  - `cli.py` — CLI на `click` (группы `projects`, команды `index/ask/character/chapter/plotline`).
  - `config.py` — настройки из env, реестр проектов (`~/.config/litmap/config.yaml`).
  - `index.py`, `ingest.py` — чтение корпуса, чанкинг, построение sqlite-индекса.
  - `retrieve.py`, `router.py`, `synthesize.py` — поиск и генерация ответов через LLM.
  - `llm.py` — обёртки над OpenAI-совместимыми эндпоинтами (чат и эмбеддинги).
  - `paths.py` — пути конфигов/данных, загрузка `.env`.
  - `prompts/` — шаблоны промптов.
- Тесты: `tests/test_core.py` (pytest, tmp_path + monkeypatch для изоляции реестра).

## Сборка, окружение, тесты

- Виртуальное окружение: `.venv/`. Установка: `pip install -e ".[dev]"`.
- Рабочие ключи/URL — в `.env` (не коммитится), схема — в `example.env`.
- Тесты:
  ```
  python -m pytest
  ```
  (конфиг уже в `pyproject.toml`: `testpaths = ["tests"]`, `pythonpath = ["src"]`.)
- После правок тесты должны проходить. Запускай `python -m pytest` для проверки.

## Ключевые соглашения

- Тип файла берётся из YAML-frontmatter (`type: character`) или из пути:
  `characters/`, `lore/`, `plotlines/` — карточки/лор; любая другая верхняя папка — рукопись,
  вложенные `chapters/` — главы той же книги.
- Проект задаётся `-p`/`--project`, `LITMAP_PROJECT` или определяется из текущей папки.
- `--work` ограничивает поиск одной рукописью (главы + общие `characters/`/`lore/`).
- Изменение внешнего поведения CLI должно отражаться в README.md.

## Сетевые зависимости

- Локальные OpenAI-совместимые эндпоинты: эмбеддинги и чат (см. `example.env`).
- Внешний LLM вызывается только в рантайме CLI (`ask/character/chapter/plotline`);
  тесты от него не зависят.
